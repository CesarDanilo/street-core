## 🚀 Sobre o projeto

Este projeto foi desenvolvido com foco em:

- 🎯 UI/UX moderna e imersiva  
- ⚡ Performance e responsividade  
- 🧱 Componentização com React  
- 🎨 Estilização com Tailwind CSS  

A proposta é simular uma **loja online de moda urbana**, com destaque para identidade visual forte e navegação fluida.

---

## 🛠️ Tecnologias utilizadas

- ⚛️ React.js  
- 🎨 Tailwind CSS  
- ⚡ Vite  
- 🎯 Lucide Icons
